How to Update mvrt.com in 3 Steps

1. Sign in with GitHub

Automatically pulls the latest mvrt-115/mvrt-115.github.io content, events, and assets.

2. Click Anything to Edit

Edit text & font sizes directly on screen, click photos to swap from your local assets/ folder, and add events on the Calendar.

3. Push or Export .ZIP

Push your changes to a dated GitHub branch (update-YYYY-MM-DD) for review or export a ready-to-host .zip.
