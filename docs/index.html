How the Tool Works

Every page on the site is stored in a structured JSON file (site-data/mvrt-site.json) and edited directly inside the preview.

Calendar & Google Calendar Sync

Click any date cell on the monthly grid to add or edit events, sync individual events directly to Google Calendar, and keep the embedded team calendar URL up to date on the same page.

Structured Roster, History & Assets

Add or remove mentors, team history years, leadership entries, past robots, technical binder PDFs, sponsor promo notes, and footer links without touching HTML or CSS files.
